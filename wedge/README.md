# Wedge — four cheap acts

Ugly on purpose. Tests one claim:

> A selection on a live page is a decision site — note, question, park-with-why, or release.

## Run

Open `index.html` in a browser (double-click or):

```bash
open wedge/index.html
```

Loops persist in **localStorage** for that origin. No server, no account, no Obsidian.

## Use with Week 1

1. Follow [`docs/week1-self-lab.md`](../docs/week1-self-lab.md).
2. Log sparks in [`logs/spark-log.md`](../logs/spark-log.md) (bookmarklet on the wedge page copies a block).
3. Use this board when you want the four acts as open loops — not as a scoreboard.

## Out of scope

Mirror, metrics, AI, sync, extension packaging, browser fork.
