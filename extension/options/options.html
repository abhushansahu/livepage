Agents

LivePage calls the Cursor Agent CLI (agent) and Claude Code CLI (claude) already on this machine. No API keys. Keep npm run agent-host running in the LivePage repo. The host only listens on loopback and pairs with this extension; web pages cannot invoke it.

Checking agent host…

Optional CLI paths when starting the host: LIVEPAGE_CURSOR_BIN and LIVEPAGE_CLAUDE_BIN. The host ignores binary paths and folders sent from the browser.

Experiments

Flag-based surfaces. Turn rooms off if the dashboard gets loud. A/B changes the default mix; your checkboxes still win.

RSS feeds

Paste one feed URL per line. Optional tags after a URL, or one shared tag set for the whole paste. You can also add a feed from a page that advertises RSS.

    Stored pages

    LivePage only keeps a page once you highlight, star, list, tag, or import it. Opening a page leaves nothing behind. Earlier builds recorded every page you opened, which buried the feed and skewed every "never opened" and "% read" number — clear those here.

    Git vault

    Bind the cloned Obsidian vault (a git repo). LivePage writes open markdown there. Git keeps two machines in sync — Chrome cannot push.
