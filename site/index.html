A selection on a live page is a decision site

Most tools treat the web as something to clip and file. That misses the moment that actually matters: you are in the habitat of the page, mid-thought, and you need a cheap way to couple, mark fog, or park a why.

Reader views strip the visual rhetoric that steered your attention. Annotation that only works after capture is annotation of a specimen, not of the living animal.

What it does

Built as a layer over the Chrome you already live in. Nothing is stored just because you opened a tab.

On the page

Select a span. Six highlight colors and a comment. Notes sit in a reserved right margin, aligned to the quote — Google Docs / Notion style, not a floating overlay.

Key idea Action Question Concern Insight Evidence

Threads can fork

Any message can branch. You and an agent can take different readings of the same span without overwriting each other. Ask Cursor or Claude Code; they get a parsed packet, not a second copy of the page.

Scroll is the truth

Reading status is how far you actually got, not a clip checkbox. Opening a page and leaving leaves no trace. LivePage writes a record the first time you keep it: highlight, comment, star, list, tag, or import.

Dashboard of open loops

Untouched Watch Later, X bookmarks, Reddit saves, RSS, half-read pages, and comments still waiting keep coming back. Hide rooms that get loud. Variant A is feed-first; B starts in lists.

This Chrome’s sessions

Harvest X bookmarks, Reddit saved, and YouTube Watch Later from the profile you already signed into. No second login. Feeds can be added from a page that advertises RSS, or from Settings.

Obsidian / git vault

Bind a vault folder. Write vault dumps ordinary markdown plus catalog.json. GitHub is the sync bus between machines. Chrome cannot push for you.

Install

Load unpacked into the Chrome you already use. Homebrew cannot inject an extension into that profile.

  1. Clone the repo, then open chrome://extensions, enable Developer mode, and Load unpacked → select the extension/ folder. Pin LivePage.
  2. Browse as usual. Alt+H highlights a selection, Alt+M comments, Alt+Shift+L opens the dashboard.
  3. For in-thread agent replies, keep npm run agent-host running in the repo. The host binds loopback only and pairs with this extension — web pages cannot invoke it. No cloud API keys.

Limits, honestly

This is an extension, not a research browser. It cannot rewrite navigation the way Horse Trails does.

Highlights use text-quote selectors. If a page rewrites the paragraph, the mark may not restore. Infinite-scroll feeds snapshot themselves when you highlight, so the anchor has somewhere to live.

The extension runs on every http(s) page because the product is “think on the live web.” Harvest uses the cookies of this Chrome profile. If you are not logged into X here, LivePage cannot invent that session.

Agent replies stay on your machine. If the host is down, you still have the packet and can paste a reply back by hand.
